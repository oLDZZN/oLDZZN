# Lucas — LDZZN

Desenvolvo bots para Discord, automações, integrações e soluções backend sob medida.

Meu foco é transformar processos manuais e ideias de comunidade em sistemas organizados, confiáveis e preparados para evoluir.

## O que eu construo

- Bots para atendimento, moderação, economia e operação de comunidades no Discord.
- APIs e serviços backend com integrações externas e persistência de dados.
- Automações para reduzir tarefas repetitivas e centralizar fluxos.
- Ferramentas personalizadas para comunidades, equipes e pequenos negócios.
